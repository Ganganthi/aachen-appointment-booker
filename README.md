# Aachen Ausländeramt Appointment Booker

This Python script automates the process of checking for and optionally booking an appointment at the **Ausländeramt (Foreigners' Office)** in Aachen, Germany.

> ⚠️ **Note:** This project is **no longer maintained**. I no longer live in Aachen and am not actively updating or testing this script.

---

## 🚀 Features

- Uses **Selenium** to open a Chrome browser and navigate through the official appointment system
- Automatically searches for available appointments
- Can either:
  - Book the first available slot, or
  - Send a **Windows notification** when a slot becomes available
- Reduces the need for manual checking and refreshing

---

## ⚙️ Usage

Add your data to the python script and run it:

```bash
python3 book.py
```
